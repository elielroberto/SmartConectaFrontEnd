🏢 SmartConectaFrontEnd

O SmartConecta é um projeto acadêmico desenvolvido durante a faculdade como um trabalho extensivo, semelhante a um TCC, com o objetivo de criar uma plataforma web para gestão de condomínios.

A aplicação foi pensada para facilitar a comunicação entre síndicos e moradores, trazendo mais transparência, organização e controle financeiro no dia a dia do condomínio.

Este repositório representa a parte Front-End do projeto.

 Objetivo do Projeto

O SmartConecta tem como foco:

Melhorar a comunicação entre síndico e moradores

Exibir balancetes financeiros mensais

Organizar gastos e receitas do condomínio

Oferecer uma interface simples, moderna e intuitiva

Simular um sistema real de gestão condominial

O projeto nasceu como uma solução acadêmica, mas com visão prática de mercado.

 Contexto Acadêmico

O SmartConecta foi desenvolvido por alunos do curso de Análise e Desenvolvimento de Sistemas na
Universidade Municipal de São Caetano do Sul (USCS).

A proposta era criar um sistema completo que simulasse uma aplicação real para gestão de condomínios, desde a interface até a ideia de regras de negócio.
